# Hexahedron Rules

Quality markers:
- `P`: positive weights
- `N`: some negative weights
- `I`: all quadrature points are strictly inside the reference element
- `B`: some quadrature points lie on the boundary
- `O`: some quadrature points lie outside the reference element
